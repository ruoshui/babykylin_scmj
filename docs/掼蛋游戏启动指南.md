# 掼蛋游戏启动指南

本文档说明如何启动当前仓库中的掼蛋服务端。当前仓库已移除四川麻将服务端玩法模块，只保留掼蛋房间、掼蛋牌型规则和 `gd_*` 掼蛋 Socket 动作。

> 注意：本项目原始客户端是 Cocos Creator 工程。当前提交完成的是掼蛋服务端可启动版本；如果需要完整 App/H5 桌面 UI，需要继续把 Cocos 客户端的麻将桌面替换为掼蛋牌桌。

## 1. 环境要求

- Node.js：建议使用项目原始要求的 Node.js 6.x。
- MySQL：5.1+，字符集使用 `utf8`。
- 操作系统：Windows、macOS、Linux 均可；以下命令以 Linux/macOS 为主。

## 2. 初始化数据库

1. 创建数据库：

```sql
CREATE DATABASE db_babykylin DEFAULT CHARACTER SET utf8 COLLATE utf8_general_ci;
```

2. 导入表结构和示例数据：

```bash
mysql -uroot -p db_babykylin < server/sql/db_babykylin.sql
```

3. 检查配置文件：

- Linux/macOS 默认读取 `server/configs.js`，该文件默认复用 `server/configs_mac.js`。
- Windows 批处理默认读取 `server/configs_win.js`。
- 如果 MySQL 账号、密码、数据库名不同，请修改对应配置文件中的 `exports.mysql()`。

## 3. 启动服务端

### Linux/macOS 一键启动

```bash
cd server
./start_all.sh
```

启动后会拉起 3 个进程：

| 服务 | 入口 | 默认端口 | 说明 |
| --- | --- | --- | --- |
| 账号服 | `account_server/app.js` | `9000` | 登录、游客账号、版本信息 |
| 大厅服 | `hall_server/app.js` | `9001` / `9002` | 创建房间、加入房间、游戏服注册 |
| 游戏服 | `game_server/app.js` | `9003` / `10000` | 掼蛋房间、出牌、过牌、结算 |

日志文件：

```text
server/account_server.log
server/hall_server.log
server/game_server.log
```

### Linux/macOS 停止服务

```bash
cd server
./stop_all.sh
```

### Windows 启动

在 `server/` 目录下分别双击或依次执行：

```text
1.account_server.bat
2.hall_server.bat
3.game_server.bat
```

## 4. 掼蛋房间配置

创建房间时传入的房间配置只保留掼蛋字段，示例：

```json
{
  "type": "guandan",
  "maxGames": 4,
  "baseScore": 1,
  "startLevel": 2,
  "tribute": true,
  "wildCard": false,
  "bombScore": false
}
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| `type` | 固定为 `guandan`，服务端会强制创建掼蛋房间 |
| `maxGames` / `jushuxuanze` | 局数，可为 `4`、`8`、`16`，也兼容索引 `0`、`1`、`2` |
| `baseScore` / `difen` | 基础分，默认 `1` |
| `startLevel` | 首局级牌，范围 `2` 到 `14`，其中 `14` 表示 A |
| `tribute` | 是否启用进贡配置位，当前服务端保留字段 |
| `wildCard` | 是否启用逢人配配置位，当前基础牌型先按普通牌处理 |
| `bombScore` | 是否启用炸弹分配置位，当前服务端保留字段 |

## 5. 掼蛋 Socket 事件

通用事件仍沿用原平台协议：

- `login`
- `ready`
- `chat`
- `quick_chat`
- `voice_msg`
- `emoji`
- `exit`
- `dispress`
- `dissolve_request`
- `dissolve_agree`
- `dissolve_reject`
- `game_ping`

掼蛋动作事件：

| 方向 | 事件 | 参数 | 说明 |
| --- | --- | --- | --- |
| 客户端 -> 服务端 | `gd_play_cards` | `{ "cards": [0, 13] }` 或 `[0, 13]` | 当前操作玩家出牌 |
| 客户端 -> 服务端 | `gd_pass` | `{}` | 当前操作玩家过牌 |
| 服务端 -> 客户端 | `gd_game_start_push` | 开局数据 | 发牌、级牌、座位、剩余牌数 |
| 服务端 -> 客户端 | `gd_turn_push` | 当前操作数据 | 仅发给当前操作玩家 |
| 服务端 -> 客户端 | `gd_turn_notify_push` | 当前操作座位 | 广播当前轮到谁 |
| 服务端 -> 客户端 | `gd_play_cards_notify_push` | 出牌数据 | 广播出牌和剩余张数 |
| 服务端 -> 客户端 | `gd_pass_notify_push` | `{ seatIndex }` | 广播过牌 |
| 服务端 -> 客户端 | `gd_trick_over_push` | `{ nextSeat }` | 一轮结束，下一轮先手 |
| 服务端 -> 客户端 | `gd_player_finish_push` | `{ seatIndex, order }` | 玩家出完牌 |
| 服务端 -> 客户端 | `gd_round_result_push` | 单局结算 | 名次、升级、积分 |
| 服务端 -> 客户端 | `gd_game_over_push` | 总结算/解散 | 房间结束 |
| 服务端 -> 客户端 | `gd_sync_push` | 同步数据 | 断线重连同步 |

## 6. 验证服务端能否运行

可先执行语法检查和规则测试：

```bash
node -c server/game_server/roommgr.js
node -c server/game_server/socket_service.js
node -c server/game_server/poker_utils.js
node -c server/game_server/guandan_rules.js
node -c server/game_server/gamemgr_guandan.js
node server/tests/guandan_rules_test.js
```

规则测试成功时会输出：

```text
guandan_rules_test passed
```

## 7. 常见问题

### 7.1 启动后连接 MySQL 失败

检查配置文件中的：

```js
exports.mysql = function(){
    return {
        HOST:'127.0.0.1',
        USER:'root',
        PSWD:'123456',
        DB:'db_babykylin',
        PORT:3306,
    }
}
```

确保数据库名、账号、密码与本机 MySQL 一致。

### 7.2 端口被占用

默认端口为 `9000`、`9001`、`9002`、`9003`、`10000`、`12581`。如果端口被占用，请修改 `server/configs.js` 或对应平台配置文件。

### 7.3 客户端仍看到麻将资源

本次已删除四川麻将服务端玩法逻辑，服务端只接受掼蛋房间配置和掼蛋动作。原 Cocos 客户端资源仍需要后续替换为扑克桌面 UI，启动服务端不依赖这些客户端资源。
