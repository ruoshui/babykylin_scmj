# 客户端掼蛋牌桌说明

## 已增加脚本

- `client/assets/scripts/PokerMgr.js`：扑克牌名称、花色、颜色、牌力和排序工具。
- `client/assets/scripts/components/GuandanTable.js`：第一版掼蛋牌桌覆盖层。
- `client/assets/resources/poker/cards.json`：扑克牌文本资源清单，正式美术版可按该结构替换 PNG/图集。

## 已对接协议

客户端 `GameNetMgr` 已对接以下掼蛋事件：

- `gd_game_start_push`
- `gd_sync_push`
- `gd_turn_push`
- `gd_turn_notify_push`
- `gd_play_cards_notify_push`
- `gd_pass_notify_push`
- `gd_trick_over_push`
- `gd_player_finish_push`
- `gd_round_result_push`
- `gd_game_over_push`

客户端出牌和过牌方法：

```js
cc.vv.gameNetMgr.playGuandanCards(cards);
cc.vv.gameNetMgr.passGuandan();
```

## 当前 UI 形态

当前桌面是代码绘制的占位 UI：绿色桌面、文本扑克牌、出牌/不要按钮、房间信息、剩余牌数和上轮出牌信息。

它的目标是先替换麻将桌面的交互入口并打通服务端协议。正式上线前建议继续补：

1. 扑克牌图片图集。
2. 出牌动画。
3. 队友标识。
4. 进贡/还贡 UI。
5. 结算面板美术。
6. Cocos 场景节点级重构，彻底移除旧麻将节点。
