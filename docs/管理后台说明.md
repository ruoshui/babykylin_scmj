# 掼蛋管理后台说明

## 地址

默认地址：

```text
http://127.0.0.1:9100/
```

默认密钥：

```text
change_me_admin_key
```

请在 `server/configs.js` 实际引用的配置文件中修改 `ADMIN_KEY`。

## 功能

- 用户管理：查询用户、加减房卡。
- 房间查看：查看当前数据库中的房间、座位、配置和游戏服地址。
- 战绩查看：按用户 ID 查看用户历史战绩 JSON。
- 公告配置：写入运行配置，并同步更新 `t_message` 的公告内容。
- 在线概览：查看用户总数、房间数、处于房间中的用户数。
- 运营配置：修改掼蛋 4/8/16 局房卡消耗、进贡、逢人配、炸弹分配置位。
- 版本配置：维护客户端版本号和下载地址配置。

## 接口安全

所有后台接口都要求 `key` 参数等于 `ADMIN_KEY`。例如：

```text
/api/users?key=change_me_admin_key
```

`dealer_api` 的 `/get_user_info` 和 `/add_user_gems` 也已增加同样的密钥校验。
