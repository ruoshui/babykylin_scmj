# 掼蛋游戏改造说明

本仓库已经完成第一阶段“只保留掼蛋服务端玩法”的改造。服务端房间创建、玩法路由、牌型规则、出牌/过牌协议和单局结算均以掼蛋为唯一玩法。

## 已完成内容

- 房间创建只构建 `type: "guandan"` 的掼蛋配置。
- 游戏服只加载 `server/game_server/gamemgr_guandan.js`。
- Socket 动作只保留通用房间/聊天/解散事件和掼蛋动作事件。
- 新增 108 张扑克牌工具、掼蛋牌型识别、比牌、队伍和升级计算。
- 新增掼蛋规则测试脚本。
- 新增启动指南：`docs/掼蛋游戏启动指南.md`。

## 当前掼蛋动作

| 事件 | 说明 |
| --- | --- |
| `gd_play_cards` | 当前玩家出牌 |
| `gd_pass` | 当前玩家过牌 |
| `gd_game_start_push` | 开局发牌 |
| `gd_turn_push` | 通知当前玩家操作 |
| `gd_turn_notify_push` | 广播当前操作座位 |
| `gd_play_cards_notify_push` | 广播出牌 |
| `gd_pass_notify_push` | 广播过牌 |
| `gd_trick_over_push` | 一轮结束 |
| `gd_player_finish_push` | 玩家出完 |
| `gd_round_result_push` | 单局结算 |
| `gd_game_over_push` | 总结算或解散 |
| `gd_sync_push` | 断线重连同步 |
