# 幼麟棋牌 - 掼蛋服务端改造版

本仓库已从原四川麻将玩法改造为**掼蛋服务端版本**：服务端只保留掼蛋房间、掼蛋牌型规则、掼蛋出牌/过牌与结算流程，不再加载四川麻将玩法管理器。

## 当前能力

- 账号服、大厅服、游戏服三进程架构。
- MySQL 房间、用户、战绩基础表。
- 掼蛋房间配置：局数、基础分、首局级牌、进贡/逢人配/炸弹分配置位。
- 掼蛋 108 张牌编码、洗牌、排序、牌力计算。
- 基础牌型识别与比较：单张、对子、三张、三带二、顺子、连对、钢板、炸弹、同花顺、天王炸。
- 掼蛋流程：准备、发牌、出牌、过牌、一轮结束、玩家出完、单局结算、升级、解散。
- Socket 事件：`gd_play_cards`、`gd_pass` 以及 `gd_*_push` 推送。
- 第一版客户端掼蛋牌桌覆盖层和扑克牌文本 UI。
- 轻量管理后台：用户查询、加减房卡、房间/战绩查看、公告/版本/掼蛋运营配置。
- 基础安全补强：大厅签名校验、账号密码登录修复、后台和 dealer API 管理密钥。
